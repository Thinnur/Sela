# Sela v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Membangun Sela v1, reader komik pribadi untuk dua akun. Pengguna menempel link Komiku atau KomikIndo, lalu semua chapter diunduh, diverifikasi, dikemas jadi CBZ, dan disimpan di Google Drive. Pengguna membacanya lewat web yang cantik di HP dan desktop, dengan progres per akun.

**Architecture:** Satu proses Python (FastAPI + uvicorn) menjalankan web, worker antrean asyncio, dan penjadwal. Data disimpan di SQLite (WAL). Arsip chapter berupa CBZ di Drive (scope `drive.file`). Di VPS hanya ada file sementara dan cache baca yang dibatasi ukurannya. Frontend berupa HTML Jinja2 ditambah JavaScript biasa, tanpa proses build.

**Tech Stack:** Python 3.12, FastAPI, uvicorn, Jinja2, httpx, Authlib, itsdangerous, Pillow, BeautifulSoup4 (`html.parser`), pytest, uv. Uji UI memakai `playwright-cli`.

**Spec:** `docs/superpowers/specs/2026-11-17-sela-design.md`. Mockup acuan: `docs/superpowers/specs/2026-11-17-sela-mockup.html`. PRD: `/srv/hermes/data/outputs/private-comic-reader-prd/PRD-Reader-Pribadi-Fathin-Putri.md`.

## Global Constraints

- Semua pekerjaan dilakukan di branch `sela-v1`. Push dan deploy hanya dengan persetujuan Fathin.
- Python 3.12. Dependensi runtime hanya fastapi, uvicorn, jinja2, httpx, authlib, itsdangerous, pillow, dan beautifulsoup4. Dependensi dev hanya pytest. Dilarang memakai Redis, Celery, Docker, React, atau build frontend.
- Server mendengarkan di `127.0.0.1:8095`. Path produksi: `/srv/sela/{app,data,cache,tmp,secrets}`.
- Chapter diproses paralel dengan bawaan 3 (`SELA_CHAPTER_PARALEL`, maksimal 4). Request per situs sumber paling banyak 8. Paling banyak 2 gambar di-decode bersamaan.
- Anggaran tmp + cache 1,5 GB, dengan cache maksimal 1 GB. Proses berhenti kalau sisa disk VPS di bawah 3 GB. Ukuran gambar maksimal 20 MB, dan satu chapter maksimal 600 gambar.
- Retry `sementara`: 60, 300, 1800, lalu 7200 detik. Setelah 5 percobaan, job dinyatakan gagal. Respons 403 atau challenge tidak pernah di-retry dan tidak diakali.
- Cek update setiap 6 jam ±30 menit. Cek manual punya jeda 10 menit.
- CSP: `default-src 'self'; img-src 'self' data:; frame-ancestors 'none'; base-uri 'none'; form-action 'self'`. Browser tidak boleh mengirim request ke host sumber.
- Gambar dikirim dengan `Cache-Control: private, max-age=86400`. Semua rute, termasuk gambar dan sampul, wajib punya sesi.
- File di Drive tidak pernah dihapus, kecuali backup DB milik Sela sendiri yang sudah melewati 14 salinan terakhir. DiBeliin, rclone, backup VPS, dan token Hermes tidak boleh disentuh.
- Token dan secret tidak boleh muncul di log, URL, atau repo.
- Teks UI dalam bahasa Indonesia santai, sentence case, dan label tombol diawali kata kerja. Teks salinan mengikuti mockup.
- Warna: kertas `#FBF6EE`, pasir `#EADFD2`, pasir muda `#F1E7DA`, lavender `#8B7FD0`, koral `#EF6B5B`, teks koral kecil `#B8443A`, mustard `#F2B544`, teal `#4AA3A2`, navy `#3E5C8A`, tinta `#3B2F2A`. Reader gelap memakai latar `#2A211D` dan bilah `#3A2F2A`.
- Font Fredoka (500) dan Nunito (400, 700) di-host sendiri.

## Review Focus

1. **Daftar sumber berisi chapter ganda** (label sama atau URL dengan fragmen). Harus menjadi satu chapter, bukan dua job (Task 8).
2. **Respons 200 berisi halaman HTML** (challenge atau error) di URL gambar. Harus ditolak sebagai gambar rusak, bukan dikemas (Task 6).
3. **Token Drive dicabut di tengah antrean.** Unduhan harus berhenti dengan status "perlu sambung ulang", tanpa retry berulang (Task 10).
4. **Disk penuh (ENOSPC) saat chapter diproses.** Status harus berubah ke `menunggu_ruang`, tmp dibersihkan, dan job tetap ada (Task 10).
5. **Sesi kedaluwarsa saat membaca.** API harus membalas 401 JSON (bukan redirect HTML), dan reader menyimpan posisi lokal untuk dikirim ulang setelah login (Task 15 dan 17).

### Task 1: Kerangka proyek, setelan, dan skema DB

**Files:**
- Create: `pyproject.toml`, `.gitignore`, `sela/__init__.py`, `sela/setelan.py`, `sela/db.py`, `tests/conftest.py`, `tests/test_db.py`

**Interfaces:**
- Produces:
  - `Setelan` (frozen dataclass): `root: Path`, `dir_data`, `dir_cache`, `dir_tmp`, `dir_secrets` (turunan dari root), `allowed_emails: frozenset[str]`, `admin_email: str`, `base_url: str`, `session_secret: str`, `chapter_paralel: int = 3`, `request_per_situs: int = 8`, `anggaran_disk: int = 1_500_000_000`, `cache_maks: int = 1_000_000_000`, `sisa_disk_min: int = 3_000_000_000`, `interval_cek: int = 21600`, `jitter_cek: int = 1800`, `cooldown_cek_manual: int = 600`, `dev_login: bool = False`.
  - `muat_setelan(env: Mapping[str, str]) -> Setelan`. Env yang dibaca: `SELA_ROOT`, `SELA_ALLOWED_EMAILS` (dipisah koma), `SELA_ADMIN_EMAIL`, `SELA_BASE_URL`, `SELA_SESSION_SECRET`, `SELA_CHAPTER_PARALEL` (dibatasi 1–4), dan `SELA_DEV_LOGIN`. Kalau ada yang wajib hilang, lempar `ValueError`.
  - `db.buka(path: Path) -> sqlite3.Connection`: WAL, `foreign_keys=ON`, `row_factory=sqlite3.Row`, `check_same_thread=False`, dan `busy_timeout` 5000. Setiap pemanggil membuka koneksinya sendiri.
  - `db.migrasi(conn) -> None`: menjalankan `SKEMA` (di bawah). Idempoten.
  - `db.pastikan_pengguna(conn, s: Setelan) -> None`: membuat baris `users` untuk setiap email di allowlist, dengan peran `admin` untuk `admin_email` dan `pembaca` untuk sisanya.

```sql
CREATE TABLE IF NOT EXISTS users(id INTEGER PRIMARY KEY, google_sub TEXT UNIQUE, email TEXT UNIQUE NOT NULL,
  nama TEXT NOT NULL DEFAULT '', peran TEXT NOT NULL CHECK(peran IN ('admin','pembaca')),
  latar_reader TEXT NOT NULL DEFAULT 'gelap' CHECK(latar_reader IN ('gelap','kertas')));
CREATE TABLE IF NOT EXISTS series(id INTEGER PRIMARY KEY, judul TEXT NOT NULL, alias TEXT NOT NULL DEFAULT '[]',
  sinopsis TEXT NOT NULL DEFAULT '', sampul TEXT, jenis TEXT, ditambahkan_oleh INTEGER REFERENCES users(id),
  ditambahkan_pada REAL NOT NULL);
CREATE TABLE IF NOT EXISTS series_sources(id INTEGER PRIMARY KEY, series_id INTEGER NOT NULL REFERENCES series(id),
  adapter TEXT NOT NULL, url TEXT NOT NULL UNIQUE, peran TEXT NOT NULL CHECK(peran IN ('utama','cadangan')),
  cek_terakhir REAL, cek_sukses_terakhir REAL, jenis_error TEXT, pesan_error TEXT, cek_berikutnya REAL,
  cek_manual_terakhir REAL);
CREATE TABLE IF NOT EXISTS chapters(id INTEGER PRIMARY KEY, series_id INTEGER NOT NULL REFERENCES series(id),
  label TEXT NOT NULL, label_normal TEXT NOT NULL, kunci_urut REAL NOT NULL, terbit TEXT,
  status TEXT NOT NULL DEFAULT 'antre' CHECK(status IN ('antre','mengunduh','mengunggah','memverifikasi','siap',
    'menunggu_ulang','gagal','menunggu_ruang','hanya_cadangan')),
  pesan_status TEXT, siap_pada REAL, UNIQUE(series_id, label_normal));
CREATE TABLE IF NOT EXISTS chapter_sources(chapter_id INTEGER NOT NULL REFERENCES chapters(id),
  sumber_id INTEGER NOT NULL REFERENCES series_sources(id), url TEXT NOT NULL,
  PRIMARY KEY(chapter_id, sumber_id), UNIQUE(sumber_id, url));
CREATE TABLE IF NOT EXISTS archives(chapter_id INTEGER PRIMARY KEY REFERENCES chapters(id), drive_file_id TEXT NOT NULL,
  sumber_id INTEGER NOT NULL REFERENCES series_sources(id), ukuran INTEGER NOT NULL, md5 TEXT NOT NULL,
  sha256 TEXT NOT NULL, jumlah_gambar INTEGER NOT NULL, manifest TEXT NOT NULL, diverifikasi_pada REAL NOT NULL);
CREATE TABLE IF NOT EXISTS reading_progress(user_id INTEGER NOT NULL REFERENCES users(id),
  series_id INTEGER NOT NULL REFERENCES series(id), chapter_id INTEGER NOT NULL REFERENCES chapters(id),
  indeks INTEGER NOT NULL, fraksi REAL NOT NULL, rev INTEGER NOT NULL, diperbarui REAL NOT NULL,
  PRIMARY KEY(user_id, series_id));
CREATE TABLE IF NOT EXISTS chapter_reads(user_id INTEGER NOT NULL REFERENCES users(id),
  chapter_id INTEGER NOT NULL REFERENCES chapters(id), status TEXT NOT NULL CHECK(status IN ('dibaca','selesai')),
  diperbarui REAL NOT NULL, PRIMARY KEY(user_id, chapter_id));
CREATE TABLE IF NOT EXISTS series_visits(user_id INTEGER NOT NULL, series_id INTEGER NOT NULL, terakhir REAL NOT NULL,
  PRIMARY KEY(user_id, series_id));
CREATE TABLE IF NOT EXISTS jobs(id INTEGER PRIMARY KEY,
  jenis TEXT NOT NULL CHECK(jenis IN ('unduh_chapter','cek_update','backup_db')), target INTEGER, sumber_id INTEGER,
  status TEXT NOT NULL DEFAULT 'antre' CHECK(status IN ('antre','berjalan','selesai','gagal')),
  percobaan INTEGER NOT NULL DEFAULT 0, jalan_setelah REAL NOT NULL DEFAULT 0, kunci_idem TEXT UNIQUE,
  checkpoint TEXT NOT NULL DEFAULT '{}', jenis_error TEXT, pesan_error TEXT, dibuat REAL NOT NULL, diperbarui REAL NOT NULL);
CREATE TABLE IF NOT EXISTS activity(id INTEGER PRIMARY KEY, pada REAL NOT NULL, jenis TEXT NOT NULL, series_id INTEGER,
  chapter_id INTEGER, user_id INTEGER, teks TEXT NOT NULL);
CREATE TABLE IF NOT EXISTS kv(kunci TEXT PRIMARY KEY, nilai TEXT NOT NULL);
```
